# 國小通用考試倒數計時器

奶油白與湖水綠的國小考場投影時鐘。獨立實作，沒有使用其他學校的校徽或程式碼。無外部字型、圖片或程式依賴。

## 使用

開啟網站，或解壓離線包後直接以瀏覽器開啟 `index.html`。選擇年級、班級與考試日期；在「考程設定」選擇三節科目，也可以輸入自訂科目、班級及提醒文字。

預設考程：第一節 08:30–09:10、下課 09:10–09:20、第二節 09:20–10:00、下課 10:00–10:20、第三節 10:20–11:00。

以電腦目前時間換算為臺灣時間（Asia/Taipei）。依指定日期及鐘點自動切換，不需按開始。中途開啟、回到分頁時皆重新計算實際剩餘時間。請先確認電腦日期及時間正確。

點「開啟提醒鐘聲」解鎖瀏覽器音效；考試前可在設定試聽。最後 5 分鐘與階段結束提醒可個別開關。重新開啟頁面需再次啟用鐘聲。

臨時加時會縮短當節後的下課，不延後下一節。最後一節最多加時三小時。若修改考程起訖時間，會清除臨時加時。加時按日期記錄，且不匯出至設定備份。

設定僅存於目前瀏覽器。使用「匯出設定／匯入設定」可在其他電腦轉移年級、班級、考程、科目與提醒設定。考試日期每次開啟預設為臺灣當天，避免沿用舊日期。未指定其他日期時，跨午夜會更新日期。

考程設定內的「預覽與設定備份」可查看考前、考試中、最後五分鐘、下課及結束畫面。預覽模式有明顯提示且不自動發出鐘聲，點「回到目前時間」離開。

## 開發驗證

使用 `node --test clock.test.cjs` 檢查時區、考程邊界、背景恢復與加時行為。專案根目錄即為可直接部署或離線使用的完整靜態網站。

## 投影可讀性

大字版本放大科目、班級、倒數與考程，並加深文字對比。1280 × 720 視窗中，倒數數字約 147 px、科目 44 px、考程科目 22 px、時段 18 px。全螢幕會收起考場選單，將空間留給考試資訊。
